# 🌤 WeatherTest — погода по городам

**WeatherTest** — учебное iOS-приложение на SwiftUI для знакомства с сетевыми запросами и отображением погоды. Введи название города, и приложение попробует получить текущие данные от OpenWeather.

## Что реализовано

- Добавление города по названию и отображение результата в списке.
- Температура, иконка погоды, время восхода и заката для добавленного города.
- Переключение единиц температуры: Celsius, Fahrenheit и Kelvin.
- Сохранение выбранной единицы температуры в настройках приложения.

Список городов хранится в памяти и после перезапуска не восстанавливается. Для загрузки погоды нужен интернет и действующий ключ OpenWeather. Ошибки сети пока выводятся в консоль; понятного сообщения на экране нет.

Интерфейс приложения — на английском языке.

## Запуск

1. Склонируй репозиторий или скачай его через **Code → Download ZIP**:

   ```bash
   git clone https://github.com/nyuchosee/WeatherTest.git
   ```

2. Открой **`WeatherTest/WeatherTest.xcodeproj`** в Xcode.
3. Проверь настройки доступа к OpenWeather в `WeatherTest/API/Constants.swift`: для запросов нужен действующий ключ.
4. Выбери схему **WeatherTest** и симулятор iPhone, затем нажми **⌘R**.

Проект создан в Xcode 12.5.1, использует режим языка **Swift 5**. В настройках проекта указана iOS 14.5, а в настройках target — iOS 14.0; более новый Xcode может потребовать изменения минимальной версии.

## Структура

```text
WeatherTest/
├── WeatherTest.xcodeproj

├── Models/              # Модели ответа и погоды
├── ViewModel/           # Подготовка данных для интерфейса
├── Global/              # Общее состояние

├── Extensions/

```
